# 三亞海棠灣・三日慢活行程

A single-file, self-contained interactive itinerary site for a 3-day couple's leisure trip to Haitang Bay, Sanya.
單檔、免建置的互動行程網站，內容為繁體中文。

**直接以瀏覽器開啟 `index.html` 即可**，無需建置工具或本機伺服器。
（首次載入需連網，以取得 Leaflet 與高德地圖圖磚。）

## 技術說明

- **單一檔案**：所有 CSS 與 JavaScript 內嵌於 `index.html`，沒有建置流程、沒有拆分檔案。
- **地圖**：Leaflet 1.9.4（CDN）搭配**高德地圖圖磚**（`webrd0{n}` 標準圖、`webst0{n}` 衛星圖）。
  高德官方 JS SDK 需申請 Key，因此採圖磚方案，免金鑰即可使用，且與高德 App 顯示同一套底圖。
- **座標系轉換**：圖資來源為 WGS-84，高德圖磚為 GCJ-02，兩者在三亞相差約 450 公尺。
  頁面內建 WGS-84 → GCJ-02 轉換（`wgs2gcj()`，已對照公開控制點驗證，誤差約 0.2 公尺），
  標記位置在執行時換算，寫在原始碼中的一律是 WGS-84 座標。
- **設計權杖**：CSS 自訂屬性定義於 `:root`，深海藍綠色系為主，金色用於餐飲、珊瑚色用於重點行程。
- **無障礙／相容**：支援 `prefers-reduced-motion`；行動版斷點 640px／860px／900px，390px 寬下無水平溢出。

## 資料來源與注意事項

- **座標**：OpenStreetMap 公開圖資與維基百科（WGS-84）。
- **票價、營業時間、房價、車資**：皆為依公開資料整理的**研究估算，非即時報價**，出發前請向酒店、景區與航空公司確認。
- **距離**：景點表中的「直線距離」為依座標計算的精確值；「車程」為一般路況的估算值。
- **旺季**：三亞多數景區以 10/1–4/30 為旺季、5/1–9/30 為淡季，本行程落在旺季區間，票價以旺季計。
