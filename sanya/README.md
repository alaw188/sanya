# 三亞海棠灣・三日慢活行程

A single-file, self-contained interactive itinerary site for a 3-day couple's leisure trip to Haitang Bay, Sanya.
單檔、免建置的互動行程網站，內容為繁體中文。

---

## 快速開始

直接用瀏覽器開啟 `index.html` 即可 —— 無需建置工具、無需本機伺服器、無需安裝任何套件。

首次載入需連網，以取得 Leaflet 與高德地圖圖磚；地圖磚載入失敗時頁面其餘部分仍可正常使用。

## 行程設計的硬性限制

這幾個條件決定了行程的骨架，改動前請先確認：

| 限制 | 影響 |
|---|---|
| **免稅購物須於起飛前 6 小時完成** | 回程 22:10 → 須於 **10/25 16:10 前**結帳。採購排在 **Day 3 退房後 14:20–16:10**，剛好落在時限內，回程只需機場提貨 |
| **退房時間為 14:00** | Day 3 的 SPA 與午餐必須排在退房前；購物則在退房後進行 |
| **酒廊禮遇至退房為止** | 退房後早餐、下午茶、Happy Hour 全部失效，Day 3 晚餐改為館內餐廳自費 |
| **HX170 為跨境航班** | 櫃檯通常於起飛前 45–60 分鐘關閉；行程以 20:40 抵達機場、19:40 離開酒店安排，保留 90 分鐘 |
| **海棠灣海況洶湧** | 全年不建議下海游泳，玩水只能靠酒店泳池（本次不排亞特蘭蒂斯水世界） |
| **免稅城只能步行前往** | 酒店專用連廊 5–10 分鐘可達，是三亞境內唯一不叫車的移動 |

## 技術說明

- **單一檔案**：所有 CSS 與 JavaScript 內嵌於 `index.html`，沒有建置流程、沒有拆分檔案、沒有相依套件管理。
- **照片**：景點卡片的實地影像外連自 **Wikimedia Commons**（自由授權），以 960px 縮圖載入、
  `loading="lazy"` 延遲載入，並附來源標註。若連不上 Commons，卡片會退回顯示漸層底色與景點名稱，
  其餘內容不受影響。**這是繼 Leaflet 與高德圖磚之後新增的外部資源依賴。**
- **地圖**：Leaflet 1.9.4（CDN）搭配**高德地圖圖磚**：
  - 標準圖 `https://webrd0{n}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8`
  - 衛星圖 `https://webst0{n}.is.autonavi.com/appmaptile?style=6`，另疊 `style=8` 取得路名
  - 高德官方 JS SDK 需申請 Key，因此採圖磚方案：免金鑰、與高德 App 同一套底圖。**未使用任何其他圖資供應商。**
- **座標系轉換**：圖資來源為 WGS-84，高德圖磚為 GCJ-02，兩者在三亞相差約 450 公尺。
  頁面內建 `wgs2gcj()` 轉換（已對照公開控制點驗證，誤差約 0.2 公尺），標記於執行時換算。
  **原始碼中的座標一律是 WGS-84**，若要調整位置請改 WGS-84 數值，不要直接填 GCJ-02。
- **設計權杖**：CSS 自訂屬性定義於 `:root`；深海藍綠色系為主，金色用於餐飲、珊瑚色用於重點行程。
- **無障礙／相容**：支援 `prefers-reduced-motion`；行動版斷點 640／860／900px，390px 寬下無水平溢出。
- **文案語系**：頁面全為繁體中文；但送往高德的 POI 搜尋關鍵字必須使用**簡體中文**（例如 `三亚亚特兰蒂斯`），
  並**完整百分編碼**後寫入 `href`，否則高德會回參數錯誤。

### 修改指引

| 想改什麼 | 改哪裡 |
|---|---|
| 地圖標記位置或內容 | `POIS` 陣列（每筆含 `wgs` / `color` / `mark` / `name` / `cat` / `desc`） |
| 備選景點 | `SCENIC` 陣列，`tier` 決定配色（`near` 綠 / `mid` 紫 / `far` 棕） |
| 動線虛線 | `ROUTES` 物件，`arrival` 與 `all` 兩組 |
| 新增地點卡片 | 地圖段落的 `.poilist` 內加一個 `.poi`，`data-poi` 需對應 `POIS` 的 `id` |
| 預算數字 | 三處需同步：KPI 卡片、費用明細表、橫條圖的 `data-full` / `data-ground` 與 JS 的 `TOTALS`、`MAX` |
| 時間軸行程 | 對應 `.day[data-day="N"]` 內的 `.ev` 區塊；`ev--gold` 為餐飲、`ev--coral` 為重點 |

## 資料來源與注意事項

- **座標**：OpenStreetMap 公開圖資與維基百科（WGS-84），再換算為 GCJ-02 顯示。
- **票價、營業時間、房價、車資**：皆為依公開資料整理的**研究估算，非即時報價**，出發前請向酒店、景區與航空公司確認。
- **景區官方資料**曾用於核對門票與時間，例如大小洞天官網（1187 年創建）、檳榔谷官網（旺季 ¥96／淡季 ¥80）、呀諾達官網、亞龍灣度假區官網（旺季 ¥158）。
- **距離**：景點表的「直線距離」為依座標計算的值；「車程」為一般路況的估算值，實際請以叫車 App 顯示為準。
- **旺季**：三亞多數景區以 10/1–4/30 為旺季、5/1–9/30 為淡季；本行程落在旺季區間，票價以旺季計。

## 驗證

沒有自動化測試。每次改動後以無頭 Chrome 手動驗證，檢查項目：

- 無 JavaScript 錯誤（`pageerror` / console error）
- 標籤配對（`div`、`section`、`article`、`span`、`script`）
- 3 個分頁切換、地圖圖層與底圖切換、地點卡片與標記雙向連動、預算切換
- 高德圖磚實際載入（host 與已載入張數）
- 預算數字在 KPI、表格、橫條圖、JS 四處一致
- **跨日引用一致性**：各日標題的統計項只描述當天，不得出現指向其他天的條目；
  調整行程順序後，所有「免稅已在 Day N 買齊」「Day N 傍晚只有散步」之類的跨日敘述必須逐一複查
- **外部連結**：高德 URI 的 `keyword` 參數必須**百分編碼**（不可含未編碼的中文、括號或中點，
  否則高德會回參數錯誤）；並以 HTTP 200 與頁面內容抽查官網連結是否有效
- 390px 寬下無水平溢出
